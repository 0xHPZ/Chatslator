# Troubleshooting

## Google Chrome

**Q: Why do I have to turn Chatslator off and back on for it to work on YouTube, or why doesn't it appear in the fullscreen chat overlay?**

**A:** This can happen when Chrome restricts Chatslator's site permissions. If Chatslator only starts working after you disable and re-enable the extension.

### How to fix it

1. Right-click the **Chatslator** icon in your browser toolbar.
2. Hover over **This can read and change site data**.
3. Select **On youtube.com**.
4. Refresh the YouTube page.

Chatslator should now load automatically without needing to turn the extension off and back on. It should also be able to appear in the fullscreen chat overlay.

---

## Opera / Opera GX

**Q: Why do I have to turn Chatslator off and back on for it to work on YouTube, even when "Always run on youtube.com" is enabled?**

**A:** Opera and Opera GX can sometimes have compatibility issues with YouTube Live Chat that prevent Chatslator from loading correctly. This can cause Chatslator to only work after being turned off and back on.

### How to fix it

1. Install **[No Service Worker](https://chromewebstore.google.com/detail/no-service-worker/mbhfklemgegigbfbfmfdmijkcnabgpmf)** from the Chrome Web Store.
2. Right-click the **Chatslator** icon in your browser toolbar.
3. Hover over **Page access**.
4. Select **Always run on youtube.com**.
5. Refresh the YouTube page.

After these steps, Chatslator should load correctly without needing to turn the extension off and back on.

## General Troubleshooting

**Q: Why isn't Chatslator translating chat or appearing correctly on a supported platform?**

**A:** The issue may be related to browser permissions, compatibility, or a recent change to the streaming platform.

### Try these steps

1. Make sure **Chatslator is enabled** and running on the current website.
2. Right-click the **Chatslator** icon in your browser toolbar.
3. Hover over **This can read and change site data**.
4. Select **On [current website]** or the equivalent option for the platform you're using.
5. Refresh the streaming page.
6. If you're using **Opera or Opera GX**, follow the additional troubleshooting steps in the **Opera / Opera GX** section above.
7. If the issue persists, restart your browser and try again.

These steps apply to supported platforms such as **YouTube, Twitch, and Kick**.
