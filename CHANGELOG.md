## [1.3.4] - 2026-06-10

### Added
- Support for both stable and recommended versions of 7TV.

## [1.3.3] - 2026-06-06

### Added
- Support for YouTube Live Chat popout pages (`youtube.com/live_chat?is_popout=1`)

---

## [1.3.2] - 2026-05-27

### Added
- Added a built-in changelog section to the options/settings page

### Fixed
- Fixed an issue where Twitch chat translation would not start properly when navigating to a streamer directly from the Twitch homepage

### Improved
- Improved the extension options/settings page UI and overall experience
- Under-the-hood improvements for a faster, smoother, and more reliable experience

### Misc
- Added more bugs (premium edition 🐛)

- Better handling of third-party extension conflicts

### Misc
- Added more bugs (premium edition 🐛)
